Дата: 05.05.2026
Автор: brainstorm + спецификация
Статус: на утверждении

## 1. Цель и не-цели

### Цель

Дать ученику ощущение движения вперёд и ценности занятий. Сейчас бот — утилитарный инструмент (расписание, ДЗ, оплата). Ученик заходит только когда надо. Прогресс и достижения создают позитивный повод взаимодействия и повышают retention без маркетинга.

Четыре компонента:

| # | Компонент | Адресат | Суть |
|---|-----------|---------|------|
| 1 | Карточка прогресса | Ученик, родитель, админ | Экран с метриками: уроки, ДЗ, план, streak |
| 2 | Достижения (milestones) | Ученик (+ пары) | Фиксированные значки за реальные результаты |
| 3 | Мини-фидбэк после урока | Ученик → админ | Одна кнопка "Как прошёл урок?" после follow-up |
| 4 | Обновление touch-шаблонов | Ученик | Больше вариативности, новые типы, новые переменные, раздельные речевые формы |

### Не-цели

- LLM/AI API для генерации текстов. Все тексты — шаблоны с подстановкой.
- Реферальная программа (отдельная итерация).
- Leaderboard / соревнование между учениками. Прогресс — личный.
- Изменение существующей навигации. Добавляется одна кнопка в "👤 Ещё".

## 2. Компонент 1: Карточка прогресса

### Где

Новая кнопка **"📊 Мой прогресс"** в меню "👤 Ещё" (экран `more_menu`).

### Экран ученика

```
📊 Твой прогресс

📅 Уроков за май: 6
📅 Всего уроков: 34
🔥 Без перерывов: 12 недель подряд
📚 ДЗ за май: 5 из 6 сделано
📌 Учебный план: 68% ✅

🏅 Достижения: 5 из 12
[список заработанных значков]
```

Строки показываются условно:
- "Учебный план" — только если у ученика есть активный план с checklist.
- "ДЗ за месяц" — только если за месяц было хотя бы 1 ДЗ.
- "Без перерывов" — только если streak ≥ 2 недель.

### Источники данных (всё уже в базе)

| Метрика | Источник | Запрос |
|---------|----------|--------|
| Уроков за месяц | `lessons` | `COUNT(*) WHERE student_id=? AND lesson_date >= first_day_of_month AND status='completed'` |
| Всего уроков | `lessons` | `COUNT(*) WHERE student_id=? AND status='completed'` (или `total_lessons` из pulse) |
| Streak | `pulse_engine._compute_streak_weeks()` | Уже реализовано |
| ДЗ за месяц (сделано / всего) | `homework` | `COUNT(*) WHERE student_id=? AND created_at >= first_day_of_month`, отдельно `status='done'` |
| Учебный план % | `study_plan_checklist_items` | `COUNT(completed=TRUE) / COUNT(*)` для активного плана |
| Достижения | `student_achievements` | `COUNT(*) WHERE user_id=?` и общее число возможных |

### Для пар

Прогресс показывается общий (уроки пары, ДЗ пары, план пары). Заголовок:

```
📊 Прогресс пары
👥 Иван и Мария
```

### Для родителя (active-режим)

Кнопка "📊 Прогресс" в child hub. Показывает те же данные ребёнка, без фидбэка.

### Admin — карточка студента

Новый блок "📊 Прогресс" в карточке студента. Те же данные + агрегат фидбэка (см. компонент 3).

### Кнопки на экране прогресса

Только **"⬅️ Назад"** — возврат в "👤 Ещё". Экран информационный, без действий.

## 3. Компонент 2: Достижения (milestones)

### Таблица достижений

| Ключ | Название | Условие | Иконка |
|------|----------|---------|--------|
| `first_lesson` | Первый шаг | Первый урок проведён (`total_lessons >= 1`) | 🎓 |
| `lessons_5` | Пятёрка | `total_lessons >= 5` | ⭐ |
| `lessons_10` | Десятка | `total_lessons >= 10` | 🔟 |
| `lessons_25` | Четверть | `total_lessons >= 25` | 🏅 |
| `lessons_50` | Полтинник | `total_lessons >= 50` | 🏆 |
| `streak_4` | Марафонец | `streak_weeks >= 4` | 🔥 |
| `streak_12` | Стальная привычка | `streak_weeks >= 12` | 💎 |
| `hw_perfect_month` | Отличник | Все ДЗ за календарный месяц сданы в срок (≥ 3 ДЗ, ни одного просроченного) | 📚 |
| `plan_complete` | Планомер | Учебный план выполнен на 100% | 📌 |
| `tenure_26w` | Полгода вместе | 26 недель с `first_lesson_date` | 🎂 |
| `tenure_52w` | Год вместе | 52 недели с `first_lesson_date` | 🎊 |
| `goal_set` | Целеустремлённый | `goal_text IS NOT NULL AND goal_text != ''` | 🎯 |

### Схема БД

```sql
CREATE TABLE IF NOT EXISTS student_achievements (
    id SERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users(telegram_id),
    achievement_key VARCHAR(50) NOT NULL,
    unlocked_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    notified BOOLEAN NOT NULL DEFAULT FALSE,
    UNIQUE(user_id, achievement_key)
);
```

Поле `notified` — отправлено ли поздравление. При backfill `notified = TRUE` (без сообщений). При ежедневной проверке — `notified = FALSE`, затем отправка и `UPDATE SET notified = TRUE`.

**Достижения не отзываются.** Если ученик заработал "Марафонец" (streak ≥ 4), а потом прервал streak — достижение остаётся. Это фиксация исторического результата, не текущего состояния.

### Scheduler job: `achievement_check_job`

- **Расписание:** ежедневно в 01:00 МСК (после `lesson_completion_job` в 00:30).
- **Логика:**
  1. Получить всех активных учеников.
  2. Для каждого — вычислить текущие метрики (total_lessons, streak, ДЗ за прошлый месяц, plan %, tenure, goal).
  3. Для каждого achievement_key — проверить условие.
  4. Если условие выполнено и нет записи в `student_achievements` — INSERT с `notified = FALSE`.
  5. Отложить отправку поздравлений до 09:00 МСК (уважать тихие часы).
- **Отправка поздравлений (09:00 МСК):**
  - Выбрать все `notified = FALSE`.
  - Отправить сообщение.
  - SET `notified = TRUE`.

### Сообщение о достижении

```
🏅 Новое достижение!

⭐ Пятёрка
Ты провёл(а) 5 уроков. Хорошее начало!
```

Текст поздравления — по одному варианту на достижение, с учётом speech_style (informal/formal/schoolchild). Хранится в `ui_text.py` как dict.

### Достижения для пар

Считаются по данным пары (уроки пары, ДЗ пары). Записываются для обоих участников (`user_id` = каждый member). Поздравление приходит обоим.

### Backfill при первом деплое

Функция `backfill_achievements(db)`:
1. Для каждого активного ученика — рассчитать все метрики.
2. Для `hw_perfect_month` — проверить каждый прошедший месяц начиная с первого урока.
3. INSERT все заслуженные достижения с `notified = TRUE` и `unlocked_at` = дата фактического события:
   - `first_lesson` → `first_lesson_date`
   - `lessons_N` → дата N-го урока (ORDER BY lesson_date LIMIT 1 OFFSET N-1)
   - `streak_N` → текущая дата (точную дату достижения streak восстановить сложно)
   - `tenure_Nw` → `first_lesson_date + N weeks`
   - `goal_set` → текущая дата
   - `plan_complete` → дата последнего checkmark (если все выполнены)
   - `hw_perfect_month` → последний день первого подходящего месяца

Вызов: кнопка "🔄 Пересчитать достижения" в "⚙️ Сервис" (admin). Одноразово при деплое + доступна на всякий случай.

### Экран достижений (внутри прогресса)

Показывается внизу карточки прогресса. Заработанные — с иконкой и названием. Незаработанные — серым с условием:

```
🏅 Достижения (5 / 12)

🎓 Первый шаг ✅
⭐ Пятёрка ✅
🔟 Десятка ✅
🏅 Четверть ✅
🏆 Полтинник — ещё 16 уроков
🔥 Марафонец ✅
💎 Стальная привычка — ещё 4 недели
📚 Отличник — сдай все ДЗ в срок за месяц
📌 Планомер — заверши учебный план
🎂 Полгода вместе — через 8 недель
🎊 Год вместе — через 34 недели
🎯 Целеустремлённый ✅
```

Для незаработанных — показываем сколько осталось (если можно посчитать) или общее условие.

## 4. Компонент 3: Мини-фидбэк после урока

### Механика

Встраивается в существующий `lesson_followup` flow. После текста follow-up — три inline-кнопки:

```
[текст follow-up от учителя]

Как прошёл урок?
😊 Отлично   😐 Нормально   😕 Сложно
```

### Схема БД

```sql
CREATE TABLE IF NOT EXISTS lesson_feedback (
    id SERIAL PRIMARY KEY,
    lesson_id BIGINT NOT NULL REFERENCES lessons(id),
    user_id BIGINT NOT NULL REFERENCES users(telegram_id),
    rating VARCHAR(10) NOT NULL CHECK (rating IN ('great', 'ok', 'hard')),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE(lesson_id, user_id)
);
```

Без свободного комментария — одно нажатие, без трения.

### Callback

`lesson_feedback:{lesson_id}:{rating}`

При нажатии:
1. INSERT в `lesson_feedback`.
2. Ответ `answer_callback_query` с коротким текстом:
   - `great` → "Спасибо! Рад, что понравилось"
   - `ok` → "Принял, спасибо!"
   - `hard` → "Спасибо за честность — разберём на следующем уроке"
3. Edit message — убрать кнопки, оставить текст follow-up.

### Адаптация под speech_style

| rating | informal | formal | schoolchild |
|--------|----------|--------|-------------|
| great | Отлично | Отлично | Супер! |
| ok | Нормально | Нормально | Ок |
| hard | Сложно | Было сложно | Трудновато |

### Отображение в admin

**Карточка студента** — новый блок:

```
💬 Фидбэк (последние 5 уроков): 😊×3 😐×1 😕×1
```

**"🎯 Today"** — если за последние 24 часа кто-то нажал 😕:

```
😕 Сложный урок: Иван (05.05)
```

Клик → переход в карточку студента.

### Для пар

Каждый участник пары отвечает отдельно (разные `user_id`, один `lesson_id`). В admin — видно оба ответа.

## 5. Компонент 4: Обновление touch-шаблонов

### 5.1. Новая структура `touch_templates.json`

Текущая: `type → tone → string`
Новая: `type → tone → speech_style → [array of strings]`

```json
{
  "progress": {
    "warm": {
      "informal": [
        "{name}, на прошлом уроке мы разобрали {topic}. Попробуй подмечать это в любом английском тексте до следующего занятия 👀",
        "{name}, {topic} — тема непростая, но ты справился. Закрепи: попробуй составить 3 своих примера 💪",
        "{name}, после {total_lessons} уроков чувствуется прогресс. {topic} — ещё один шаг вперёд"
      ],
      "formal": [
        "{name}, на прошлом уроке мы разобрали {topic}. Попробуйте обращать внимание на это в текстах до следующего занятия",
        "{name}, {topic} — тема, которая требует практики. Рекомендую составить несколько собственных примеров",
        "{name}, за {total_lessons} уроков заметен прогресс. {topic} — ещё один шаг вперёд"
      ],
      "schoolchild": [
        "{name}, помнишь, мы разбирали {topic}? Попробуй заметить это в каком-нибудь видео или песне 🎧",
        "{name}, {topic} — ты молодец, что разобрался! Попробуй придумать 3 примера сам 🚀"
      ]
    }
  }
}
```

### 5.2. Новые переменные

| Переменная | Источник | Описание |
|------------|----------|----------|
| `{name}` | `users.full_name` | Имя (уже есть) |
| `{topic}` | `parse_teacher_comment()` | Тема урока (уже есть) |
| `{partner}` | `student_group_members` | Имя партнёра в паре (уже есть) |
| `{N}` | `streak_weeks` | Недели подряд (уже есть, унифицируем с `{streak}`) |
| `{streak}` | `streak_weeks` | Алиас для `{N}`, более читаемый в шаблонах |
| `{total_lessons}` | `pulse.total_lessons` | Общее число уроков |
| `{goal}` | `users.goal_text` | Текст цели ученика |
| `{next_milestone_text}` | вычисляемое | "До 25-го урока осталось 3 занятия!" или пусто |

`{next_milestone_text}` вычисляется в touch_engine: ближайший milestone из [5, 10, 25, 50] минус total_lessons. Если разница ≤ 3 — заполняется. Иначе пустая строка (шаблон не использует).

### 5.3. Новые типы touches

| Тип | Условие срабатывания | Пример (informal, warm) |
|-----|---------------------|-------------------------|
| `milestone_approaching` | `total_lessons` в пределах 3 от [5, 10, 25, 50] | "Ещё 2 урока — и будет 25! 🏅 Продолжай в том же духе" |
| `goal_reminder` | `goal_text IS NOT NULL`, не отправлялся за последние 14 дней | "{name}, помнишь свою цель — «{goal}»? Каждый урок приближает" |

Приоритет в `select_touch_type` (обновлённый порядок):
1. `milestone_approaching` (если в зоне ±3 от milestone) — наивысший, событийный
2. `support` (если есть difficulty в комментарии) — персональный
3. `progress` (если есть topic) — персональный
4. `hw_nudge` (если есть активное ДЗ, нет комментария)
5. `goal_reminder` (если есть цель, последний goal_reminder > 14 дней назад)
6. `motivation` (если streak ≥ 3)
7. `None` — не отправлять

### 5.4. Выбор из нескольких вариантов

`render_touch_message()`:
1. Получить массив шаблонов для `type × tone × speech_style`.
2. Получить `last_template_index` из `student_touches` (последний отправленный шаблон этого типа).
3. Выбрать случайный шаблон, исключая `last_template_index`.
4. Подставить переменные.
5. Записать выбранный index в `student_touches.template_index`.

Добавить колонку `template_index SMALLINT` в таблицу `student_touches`.

### 5.5. Убрать regex-замены speech

Текущий код в `render_touch_message` делает hardcoded regex замены для formal формы. С новой структурой — шаблоны уже написаны в правильной речевой форме. Regex-логику удалить.

### 5.6. Объём шаблонов

| Тип | Тонов | Речевых стилей | Вариантов на комбинацию | Итого шаблонов |
|-----|-------|----------------|------------------------|----------------|
| progress | 4 | 3 | 3-5 | ~48 |
| support | 4 | 3 | 3-5 | ~48 |
| hw_nudge | 4 | 3 | 2-3 | ~30 |
| motivation | 4 | 3 | 2-3 | ~30 |
| milestone_approaching | 4 | 3 | 2-3 | ~30 |
| goal_reminder | 4 | 3 | 2-3 | ~30 |
| *_pair (×6) | 4 | 2 (informal/formal) | 2-3 | ~120 |

Итого: ~336 шаблонов. Писать поэтапно — сначала warm × informal/formal (основные), остальные тона — во второй итерации.

| Job | Расписание | Действие |
|-----|-----------|----------|
| `achievement_check_job` | Ежедневно 01:00 МСК | Проверка условий, INSERT новых достижений |

## 9. Миграция и обратная совместимость

### touch_templates.json

Старый формат: `type → tone → string`
Новый формат: `type → tone → speech_style → [string]`

`render_touch_message()` при загрузке проверяет формат. Если значение — строка (старый формат), оборачивает в `{"informal": [value]}`. Это обеспечивает обратную совместимость на время перехода.

### Backfill

Вызывается вручную из admin после деплоя. Идемпотентный — повторный вызов не дублирует записи (UNIQUE constraint + ON CONFLICT DO NOTHING).

### Фидбэк

Кнопки появляются только в новых follow-up сообщениях. Старые уроки без фидбэка — ок, `lesson_feedback` просто будет пустой.
