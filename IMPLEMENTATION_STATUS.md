# IMPLEMENTATION_STATUS.md

## Готово

- Персистентное FSM-хранилище, переживающее watcher-restart
- Дедупликация связей `родитель ↔ ученик`
- Единый источник ссылок на онлайн-урок из `teacher_info.json`
- Обновлённый `/help`
- Умный перенос с ближайшими свободными слотами
- Еженедельная сводка родителям
- Переключаемая тональность бренда
- Рабочие заметки для агента: текст и скриншоты
- Учебные пары: админское создание, саморегистрация, общий баланс/темп/ДЗ через основной профиль
- Подключение второго участника пары по deep-link из админской карточки пары
- Учебный план: PDF-загрузка через админку, preview/ручная выжимка, ученический экран, чек-лист подготовки, еженедельный обзор и тарифная сетка
- Отложенная доставка ДЗ: тихие часы, очередь, ручное `Отправить сейчас`, утренние batch-сообщения и мониторинг
- Поддержка отдельной ссылки на учебные материалы (`contacts.materials_url` / `contacts.filen_url`)
- «📁 Материалы» вынесены отдельной кнопкой главного меню
- Календарь как кнопка прямо в экране «Расписание», а не спрятан в Контактах
- Реквизиты больше не дублируются в главном меню — путь идёт через раздел «Оплата»
- После первого урока новому ученику автоматически приходит благодарность с реквизитами и кнопкой «Сообщить об оплате» (не ретроспективно: миграция помечает текущую базу как уже отправленную)
- Главная клавиатура ученика и родителя сжаты до ≤7 кнопок, редкие функции (Профиль, Заморозка, Опасные действия) переехали в «👤 Ещё»
- Админский экран «🎯 Сегодня»: уроки на день, кому реквизиты / ДЗ / заморозка / Inbox; «⚙️ Сервис» уплощён в один уровень; «📚 Учебный процесс» переписан в глагольный стиль с бейджем заморозок
- «💬 Inbox» для админа: ответы учеников, заявки на заморозку и первые регистрации родителей пишутся в `admin_inbox`; экран со списком, отметкой «прочитано», шорткатом «Ответить»
- Светофоры в карточках детей у родителя (🟢/🟡/🔴/⏳) с одной строкой проблемы
- Stateful CTA на главной ученика: VK-звонок за 15 мин до урока / просроченное ДЗ / нулевой баланс / напоминание о тесте уровня
- Базовый онбординг: пошаговая регистрация, welcome после регистрации, контакты, материалы, тест уровня и первые кнопки действий
- Документированный release workflow: quality gate, backup/restore, smoke check, rollback
- Startup env validation и `ExecStartPre` для systemd
- Dev-quality контур: Makefile, CI, ruff, mypy, pytest
- Операционные скрипты: validate-env, backup, restore, release smoke
