# IMPLEMENTATION_STATUS.md

## Готово

- Персистентное FSM-хранилище, переживающее watcher-restart
- Дедупликация связей `родитель ↔ ученик`
- Единый источник ссылок на онлайн-урок из `teacher_info.json`
- Обновлённый `/help`
- Умный перенос с ближайшими свободными слотами
- Еженедельная сводка родителям
- Переключаемая тональность бренда
- Рабочие заметки для агента: текст и скриншоты
- Учебные пары: админское создание, саморегистрация, общий баланс/темп/ДЗ через основной профиль
- Подключение второго участника пары по deep-link из админской карточки пары
- Учебный план: PDF-загрузка через админку, preview/ручная выжимка, ученический экран, чек-лист подготовки, еженедельный обзор и тарифная сетка
- Отложенная доставка ДЗ: тихие часы, очередь, ручное `Отправить сейчас`, утренние batch-сообщения и мониторинг
- Поддержка отдельной ссылки на учебные материалы (`contacts.materials_url` / `contacts.filen_url`)
- Документированный release workflow: quality gate, backup/restore, smoke check, rollback
- Startup env validation и `ExecStartPre` для systemd
- Dev-quality контур: Makefile, CI, ruff, mypy, pytest
- Операционные скрипты: validate-env, backup, restore, release smoke

## Ближайшая очередь

1. Онбординг новых учеников
   Сделать первые дни после регистрации более полезными: быстрый старт, понятные следующие шаги, мягкие возвраты к боту и первые учебные действия.
2. Сегментные рассылки
   Отправка не всем ученикам сразу, а по фильтрам: новые, без уроков на неделе, с нулевым балансом, очные, онлайн, на ты, на Вы.
3. Расширение тональности бренда на все статические экраны
4. Точечные UI-polish проходы по редким админским сценариям
