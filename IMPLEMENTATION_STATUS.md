# IMPLEMENTATION_STATUS.md

## Готово

- Персистентное FSM-хранилище для переживания watcher-restart.
- Дедупликация связей `родитель -> ребёнок`.
- Единый источник ссылок на онлайн-занятия через `teacher_info.json`.
- Обновлённая `/help`-справка.
- Умный перенос с 2–3 ближайшими свободными слотами.
- Еженедельная сводка родителям.
- Переключаемая тональность бренда.
- Рабочие заметки из бота: текст и скриншоты.
- Ручное уведомление `Бот обновился!` без автоспама на каждый рестарт.

## Ближайшая очередь

1. Сегментные рассылки.
   Рассылать сообщения не всем подряд, а по фильтрам: новые ученики, без уроков на неделе, нулевой баланс, только очные, только `на Вы`, только `на ты`.
2. Более тонкая copy-настройка для всех статических экранов под выбранную тональность бренда.
3. Расширение weekly digest для родителей: при необходимости добавить статус оплаты и ближайший урок.
